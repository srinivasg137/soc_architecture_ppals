The complete journey

A GPU, SSD or network adapter can be electrically present while still invisible to software. Bringing it into use crosses several boundaries: power and reset, receiver detection, link training, configuration enumeration, driver binding and data movement.

Power & reset → Detect → Train → L0 → Enumerate → Driver

Link bring up

Power and clock stability allow the ports to begin their work. Link training establishes communication across the lanes. Reaching L0 is an important physical link milestone, but it does not mean that software has discovered the Function or allocated its resources.

Software discovery

Firmware and the operating system discover Functions through configuration access. Resource allocation and driver initialization follow. When bring up fails, identify the last boundary that has actually succeeded instead of treating the whole process as one event.
